# Tooling & credits

This project was built and remediated with the help of AI-assisted development
tools (code generation, audit, and review) alongside the maintainer's own work.
No agent roster, per-agent prompts, or model assignments are tracked in the
repository — the code, tests, and measurements speak for themselves.

Key open-source the bot stands on:
- [libsecp256k1](https://github.com/bitcoin-core/secp256k1) (Bitcoin Core) — ECDSA
- [OpenSSL](https://www.openssl.org/) — TLS
- [libcurl](https://curl.se/) — HTTP/2-ready transport
- [pycryptodome](https://www.pycryptodome.org/) + [coincurve](https://github.com/ofek/coincurve) — Python cross-verification
